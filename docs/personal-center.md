# 个人中心界面更新

日期：2026-10-22。

## 目标与范围

将原先分散的账号条、重复的“偏好设置”标题和长设置卡整合为个人中心。沿用现有品牌与五种外观、六种点缀色，优先适配 iPhone，同时兼顾平板与桌面。

## 界面组织

- 个人通行证整合昵称、邮箱和已验证状态；信息来自现有账号接口，不生成虚拟会员等级、统计或身份编号。
- 关注车手单独展示头像、车队、赛季排名和积分，支持在对话框中选择、更换、取消关注以及查看已有车手详情。
- 提供赛事回放、观赛中心与赛事速览入口，复用现有路由和页面。
- 外观以界面缩略图展示，点缀色提供颜色和文字标签；使用偏好与账号安全分组展示。
- 隐私、密码重置、退出登录、主屏幕添加说明及图片/赛道来源入口保留。导航统一命名为“我的”。

## 取舍与边界

采用通行证与分组卡片，替代单一长列表，强化账号身份并便于快速找到常用功能。桌面使用双列，手机使用单列；不增加数据库、图片服务或新的认证依赖。关注、时区和外观继续仅保存于本机，不宣称跨设备同步。账号请求、会话检查和退出沿用既有逻辑。

## 验证

- 项目完整检查及生产构建通过，包含原有 62 项认证检查。
- 本地已登录环境检查桌面及 390 像素窄屏；浅色、松林绿与多种点缀色无横向溢出。
- 手动验证车手选择、刷新恢复、取消关注、时区切换与恢复、赛事回放导航、主屏幕说明对话框。
- 测试完成后恢复原有本机外观、点缀色、时区和关注状态。
