# 围场口袋微信小程序接入方案

准备日期：2026-10-26。基于当前网页版及 Android 1.0.3。

## 当前阶段

维护者已确认没有营业执照，采用**个人主体、原生小程序**方案。已准备 [native/wechat](../native/wechat/README.md) 0.1.0 工程，包含赛程、成绩、积分榜、天气、车手档案、新闻、回放搜索入口和账号云同步接入代码。维护者的 AppID 已在本机配置，工具已编译并验证部分页面；尚未上传、通过审核或成为可在微信搜索的发布版本。验证结果见[测试记录](../native/wechat/TESTING.md)。

## 两种接入方式

| 方案 | 适用前提 | 实现方式 | 界面与维护 |
| --- | --- | --- | --- |
| 网页承载方案 | 小程序后台具备 web-view 及业务域名配置资格 | 小程序使用 web-view 载入 https://f1.xiaodinglab.com/，增加微信侧分享、错误反馈与页面入口 | 最大程度复用现有界面；网页更新继续沿用现有发布流程 |
| 原生小程序方案 | 申请主体与服务类目允许相应功能 | 使用 WXML、WXSS 和小程序 JavaScript 重建页面，调用现有业务 API | 复用数据和账号服务；页面、交互及运行时需要单独维护 |

腾讯的域名接入文档明确：仅企业版小程序可配置业务域名，并通过 web-view 访问 H5。不能先按网页承载方案做好，再假设个人账号可以直接上线。个体工商户主体应在实际注册后台核对对应资格后确定。

来源：[腾讯云小程序和公众号相关的域名配置指南](https://cloud.tencent.com/document/product/1301/100434)。

## 现有功能迁移清单

| 功能 | 网页承载方案 | 原生小程序方案 |
| --- | --- | --- |
| 赛程、场次、成绩、积分榜 | 复用现有页面 | 重建页面，复用 /api/data |
| 比赛地天气 | 复用页面与刷新策略 | 原生天气卡片，复用 /api/weather；保留真实获取时间 |
| 车手档案、历史成就和头像 | 复用现有页面 | 接入 /api/drivers/:id；按平台图片与下载域名规则加载资源 |
| 动态新闻 | 复用现有页面 | 接入 /api/news；原始出处、时间及订阅摘要保持一致 |
| 技术分析和遥测 | 核验微信网页环境中的图表与性能 | 单独适配图表、采样数据和大文件加载 |
| 3D赛道 | 核验微信设备 WebGL 能力 | 单独适配小程序 Canvas/WebGL，不能直接当作网页组件导入 |
| 邮箱账号、头像与跨设备设置 | 验证网页会话、上传与邮件回跳 | 适配会话、上传和退出；用户偏好继续以云端为准 |
| 微信一键登录 | 作为额外账号接入评估 | 需要 AppID、服务端凭据与账号绑定流程，单独实现 |
| 比赛回放 | 核验链接在小程序网页容器中的打开行为 | 使用平台允许的入口与交互；不假设可以任意打开外站 |
| 五星体育和腾讯视频 | 逐项验证平台支持的播放与外部跳转 | 重新设计观赛入口，Android 原生观看窗口和浏览器扩展不能直接移入小程序 |
| Android桌面组件 | 属于现有Android安装包 | 不属于微信小程序工程，继续维护Android版本 |
| 分享比赛与阵容 | 增加小程序路径及分享配置 | 原生小程序分享卡片、页面参数与海报能力 |

## 注册步骤

1. 在电脑打开[微信公众平台](https://mp.weixin.qq.com/)，选择“立即注册”→“小程序”。
2. 使用自己的邮箱注册并完成激活；密码、验证码和主体资料由本人填写。
3. 按已确定的个人主体路线完成管理员绑定与信息登记，所有资料按实际情况填写。
4. 在后台补充名称、图标、介绍和与实际功能相符的服务类目，核对平台显示的资质与备案要求。
5. 在“开发管理”→“开发设置”找到 AppID。后续可提供 AppID；AppSecret、上传私钥及账号密码应自行保管。
6. 使用微信开发者工具导入匹配方案的工程。配置平台要求的服务器域名；网页承载方案还要配置业务域名并完成域名文件验证。
7. 完成开发者工具编译、iPhone/Android微信真机预览、体验版验收后，再上传、提交审核和发布。

注册步骤参考：[腾讯云小程序配置及开通审核服务](https://cloud.tencent.com/document/product/1598/80508)。项目配置格式参考：[微信官方示例工程](https://github.com/wechat-miniprogram/miniprogram-demo/blob/master/project.config.json)。上传所需项目与凭据说明：[微信官方 miniprogram-ci](https://github.com/wechat-miniprogram/miniprogram-ci-dist)。

## 工程约束与验收

- 小程序作为独立客户端维护，复用现有正式站业务服务；当前网页版和Android发布链路保持独立。
- 账号设置继续跨设备同步。原生方案需验证微信请求头、会话保存、重新登录与退出清理；维持现有来源校验和账号归属保护。
- 私钥和AppSecret仅在需要的服务端或私有发布环境使用。源代码、二维码、分享参数与GitHub提交中不放会话或密钥。
- 未配置AppID及合法域名时，可继续做源代码和数据契约验证；不会把静态检查写成微信真机或审核验收通过。
- 验收覆盖：冷启动、弱网、赛季/分站切换、积分与车手详情、天气时间、登录与退出、云同步、头像、分享、观赛入口，以及iPhone和Android微信的布局与交互。
- 正式发布以对应主体、服务类目和微信后台审核结果为准。认证、域名与发布事项以届时后台显示的实际要求处理。
