# Android 0.7.0 发布说明

## 安装

[下载 APK](https://f1.xiaodinglab.com/downloads/Paddock-Pocket-0.7.0.apk) · [版本、SHA-256 与签名摘要](../public/downloads/android-build.json) · [源码构建](../native/android/README.md)

支持 Android 8.0 及以上，目标 SDK 为 36。下载完成后按 Android 系统提示确认安装。已有 0.6.0 用户可在“我的 → 设备支持”检查更新或直接下载覆盖安装。0.5.0 没有新版检查机制，需要手动升级。

0.7.0 保持包名 `dev.paddock.pocket`，版本码为 `7`。签名证书与 0.6.0 一致，签名证书 SHA-256 为：

```text
6116cdaa2de6ae30737976e789fb582c602bc944e0aacd7da6f0755e87340c9d
```

## 与网页版的关系

安装包直接加载 `https://f1.xiaodinglab.com`，因此使用同一套登录、赛程、排名、天气、遥测、回放与个人页面。它需要联网，不打包旧版离线网页。网页发布后重新加载可获得新内容；Android 系统功能变化需要更新 APK。

打开 App 时检查原生版本，另提供手动检查。自动检查在当前进程中有限频；不会后台推送或静默安装。更新地址限于本站的固定下载路径。

## 原生功能

- AppWidget：下一场倒计时、天气及最多三位关注车手。关注选择在 App 进入后台时复制给原生层。
- 系统图片选择：供账号头像裁剪使用。
- 系统文档保存：保存日历文件。
- 独立观赛窗口、腾讯视频唤起及小组件添加入口。

小组件后台工作约按 30 分钟周期由系统调度，可能受省电策略和网络影响，不保证实时计时。维护者电脑无需一直开机。小组件与网页使用各自的缓存及数据请求，更新时间可能不同。

## 发布验证

已验证 Java 编译、v2/v3 签名、ZIP 对齐、版本元数据、下载文件 SHA-256，以及与 0.6.0 的签名一致性。公开的 APK 使用现有预览证书，且未开启应用调试标记。

维护者已于 2026 年 10 月 24 日确认完成 Android 0.7.0 真机验证，应用可正常使用。当前 APK 通过项目下载渠道分发，使用现有预览签名证书；签名私钥由维护者保存。

发布脚本从原生清单读取版本并核对构建报告，自动生成下载元数据；网页下载按钮读取同一份元数据。上一版 0.6.0 APK 暂保留以便恢复。清理掉的 0.5.0 大体积旧包及历史文件已在维护者本机备份，Git 历史也保留旧版本。
