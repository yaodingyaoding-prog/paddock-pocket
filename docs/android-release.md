# Android 0.7.1 发布说明

## 本次更新

- 五星体育内置脚本更新到 SMG 0.26.0，与网站提供的安卓单文件保持字节和 SHA-256 一致。
- 支持手机直播链接 `/huikan/10`，在独立观赛窗口内打开。
- 观赛窗口显示实际载入的脚本版本，保留 HTTPS 来源限制和独立页面环境。
- APK 内附脚本 MIT 许可。构建和发布流程检查脚本版本、哈希、签名及安装包完整性。

## 安装与升级

[下载 Android 0.7.1](https://f1.xiaodinglab.com/downloads/Paddock-Pocket-0.7.1.apk) · [文件校验与签名](../public/downloads/android-build.json) · [源码构建](../native/android/README.md)

支持 Android 8.0 及以上，目标 SDK 为 36。包名保持 `dev.paddock.pocket`，版本码为 `8`。使用与 0.6.0、0.7.0 相同的签名证书，可直接覆盖安装并保留应用数据。应用内也会检查新版并提示下载安装。

```text
签名证书 SHA-256
6116cdaa2de6ae30737976e789fb582c602bc944e0aacd7da6f0755e87340c9d
```

网站页面更新会随重新加载生效，内置播放脚本随 APK 更新。本次需要安装 0.7.1 才能替换原生观赛窗口内的旧脚本。打开“探索 → 观赛中心 → 五星体育 → App 内观看”，页面载入后可看到 SMG 0.26.0 提示。

## 网页与原生功能

App 加载正式站，使用相同的登录、赛程、积分、天气、遥测、回放与个人页面。关注、主题、配色和时区按账号跨设备同步。

原生层提供桌面小组件、系统头像图片选择、日历保存、独立观赛窗口、腾讯视频 App 唤起和更新检查。小组件显示下一场倒计时、天气及最多三位关注车手，后台刷新由 Android 按电量与网络情况调度。

## 发布验证

本次完成 Java 编译、v2/v3 签名、ZIP 对齐、版本元数据、APK SHA-256 和内置脚本逐字节核对；签名与上一版一致。维护者此前已确认 0.7.0 真机可正常使用，0.7.1 的构建验证单独记录，不沿用旧 APK 的真机测试标记。

脚本源包随附的 Chromium 观察与测试记录保留在三端完整下载包内。源包记录不代替本次 APK 或真实 iOS/Android 设备的持续播放验证。

当前 APK 使用项目预览签名证书。私钥不在仓库内，原生升级由用户确认安装。0.7.0 APK 保留以便恢复。
