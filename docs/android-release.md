# Android 1.0.3 正式直装版

[下载安装包](https://f1.xiaodinglab.com/download) · [版本与 SHA-256 校验](../public/downloads/android-build.json)

## 安装与观看

1. 下载 APK，在手机上按系统提示安装。已安装旧版的用户直接覆盖安装。
2. 打开围场口袋，进入“探索 → 观赛中心”。
3. 点击五星体育的“App 内观看”，再点击画面播放。无需另外安装脚本。

## 启动与连接恢复

1.0.3 增加公共数据读取的一次限时重试、恢复联网后的失败项目重试，并修正头像版本缓存。系统返回键优先关闭当前弹层；关注阵容会同步到组件，最多分行显示三位车手。3D 赛道按窗口比例取景，窄屏工具栏和设备操作按钮重新排布。新版内置页面包含头像编码兼容模块，构建时校验网页源码指纹，防止旧资源误入新包。

首屏内置赛程、积分和对应的页面资源，包含 JS、CSS、字体、车手图片与赛道模型。正式站连接或脚本下载失败时，App 自动尝试内置首页，继续显示最近保存的数据；实时数据、登录与直播仍需网络。连接中断时提供重新连接、浏览器打开及直接观赛入口。

网站先显示已保存的赛程，各项数据独立更新。详情功能按需载入，旧版 Android WebView 的常用浏览器 API 也提供本地兼容处理。

## 升级与发布

支持 Android 8.0 及以上；版本码 12；包名 dev.paddock.pocket。保留原签名身份，可从 0.7.1 覆盖升级并保留账号数据。原生更新由 App 提示下载安装，网站页面更新在正常联网重新载入时生效。内置备用页面随 APK 更新。

这是项目直接分发的正式安装包，未在 Google Play 上架。发布包关闭调试，签名私钥不在仓库内；维护者使用加密保存口令的私有签名文件。为保证覆盖升级，签名证书延续旧版身份，证书主题字段保留历史名称。

## 验证

通过项目回归检查、编译、v2/v3 签名、ZIP 对齐、版本与 SHA-256 校验，以及内置 SMG 0.26.0 脚本逐字节核对。在 Android API 36 模拟器上验证旧版覆盖升级、赛程和积分页面及连接失败后的内置首页恢复。新版本仍需实际用户设备反馈，不沿用 0.7.0 的真机验证标记。
