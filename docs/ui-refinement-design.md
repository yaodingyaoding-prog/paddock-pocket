# 赛事主视觉与详情页更新

2026-10-22，依据维护者确认的 UI 方向实施。

## 已确认范围与假设

- 首页突出下一站大奖赛，以名称、3D 赛道、时间与倒计时建立主次；赛事入口降为横向工具区。
- 车手档案采用完整详情页，提供返回、分类与复制链接；短操作继续使用原有对话框。
- 保留五种外观及六种点缀色，车队色只承担身份和数据强调；提高辅助字号与触控区域。
- 主要使用场景为 iPhone Safari，兼容 360/390 像素手机、平板和桌面；不增加字体、图片、动画或后端服务依赖。
- 沿用已有登录保护、数据来源、更新频率、缓存和头像隐私边界，不增加账号权限或新的数据采集。
- 假定流量与部署方式不变，仍由维护者在 GitHub / Cloudflare 维护；既有数据失败状态、重试及无数据提示保留。

## 设计取舍

1. 采用单一赛事主视觉 + 四项紧凑入口。保留所有功能入口，避免同等大小卡片分散注意力；相比整屏海报，仍让赛程较早进入视野。
2. 车手档案采用带赛季参数的 hash 路由，复用已有数据和组件。相比扩大弹窗，长内容的滚动、返回和分享更自然；相比全站路由重写，改动范围更小。赛道档案沿用已有完整页面。
3. 统一字号、圆角、间距与按钮层级，通过独立样式文件维护。保留用户选定的主题与颜色；采用短时过渡并尊重减少动态效果设置。

车手分享地址通过已有登录回跳流程保留；只接受受限 hash 路径、合法车手及赛季 UUID，并重新构造本站地址，不放宽认证或外部跳转限制。历史赛季页不请求当前站造型。

## 验收重点

检查比赛主视觉、赛历切换、赛道预览、直播与回放入口；车手详情的打开、返回、刷新、直接链接、不同赛季和无数据状态；手机与桌面布局、明暗主题、键盘焦点及页面横向溢出。新路由解析纳入现有自动检查，原有业务与认证检查继续运行。
