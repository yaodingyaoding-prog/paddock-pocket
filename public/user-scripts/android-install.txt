SMG 安卓兼容版 0.26.0

只需安装一个文件：smg_fivestar.android.user.js
这是浏览器用户脚本，不是 APK，不需要安装 iPad 版的请求助手。

一、使用条件

必须使用支持用户脚本的安卓浏览器或脚本管理器。不能仅凭安装此文件，
就让一个不支持脚本的浏览器获得脚本功能。

可优先尝试 Firefox 安卓版 + Violentmonkey（暴力猴）。
Firefox 官方扩展商店中的 Violentmonkey 页面列明支持 Android：
https://addons.mozilla.org/en-US/firefox/addon/violentmonkey/

也可以在已经支持 Tampermonkey（油猴）的浏览器中使用。
部分带内置脚本功能的浏览器可以运行，但隔离方式、接口支持和加载时间不同，
不能保证所有内置引擎都适用。浏览器需要支持现代 JavaScript（包括可选链）。

二、安装

1. 把 ZIP 安装包传到安卓设备，用文件管理器解压。
2. 在浏览器的脚本管理器中导入 smg_fivestar.android.user.js。
   如果管理器不能直接读取本地文件，使用文本编辑器打开文件，复制全部内容，
   在脚本管理器中“新建脚本”，删除默认示例，粘贴并保存。
   ZIP 是传输包，请先解压，不要把它当成扩展备份 ZIP 直接导入。
3. 确认名称为“收看SMGTV电视节目（安卓兼容版）”，版本 0.26.0，且已启用。
4. 关闭以前安装的普通版、iPad 版或其他同功能脚本，避免同时修改播放器。
5. 在同一个浏览器打开：
   https://live.kankanews.com/huikan?id=10
   如果跳到 m.kankanews.com/huikan，脚本也会匹配。
6. 刷新页面，左下角应出现 SMG 状态和“全屏”按钮。
   看到“点按播放”时，点一下状态按钮或播放器的播放按钮。

三、增加的兼容处理

- 0.26.0：直接刷新当前节目的直播地址，不再只依赖回看地址恢复直播。
- 按实际页面资源识别签名版本，并使用手机站对应的平台参数。
- 拒绝把已过期的取源结果记为成功，避免旧缓存覆盖节目详情的新地址。
- 原生媒体错误导致视频暂停时，也能进入恢复流程；普通手动暂停仍保留。
- 单文件：自动适配 GM_xmlhttpRequest 回调接口、GM.xmlHttpRequest Promise 接口。
- 无 GM 接口时尝试网页原生请求。该路径受网站 CORS 限制，不能保证跨域取源成功。
- 请求有独立超时；部分引擎未触发回调时也不会永久卡住后续请求。
- 不依赖用户手动设置 UA，不强制跳转到 App，不强制开启静音。
- 支持网页视频的手动起播，以及触屏全屏按钮；全屏失败时使用原有 CSS 兜底。
- 切后台或离线时暂停定时取源与恢复检查；返回前台不自动解除用户的暂停。
- 再次检查延迟出现或更换后的播放器，避免首次加载太慢就永久错过。
- 状态只有在视频已有数据且播放时间近期推进时才显示“正在播放”。
- 保留频道 10 的自动取源范围，避免错误频道基底造成节目内容不匹配。

四、状态与排查

完全没有 SMG 按钮：
检查是否启用脚本，当前网址路径是否为 /huikan，是否使用了同一个浏览器。
脚本管理器必须支持访问网页 JavaScript。部分页面策略也可能阻止脚本注入。

SMG：页面环境未连接：
脚本能操作页面 DOM，但无法访问网页播放器对象。建议使用支持页面环境的
Tampermonkey / Violentmonkey，不要强制设为 content 隔离模式。

SMG：点按播放：
浏览器要求用户手动启动视频；点一下状态按钮。

SMG：媒体错误／NotSupportedError：
源地址或媒体解码未成功；点一下状态按钮尝试恢复。
如果持续失败，请提供浏览器名称、版本和带状态文字的截图。

五、验证范围

本地测试模拟了不同请求 API、缺失 API、超时、后台状态、播放器晚加载、
手动起播、全屏调用、重复注入及原有直播恢复逻辑。
详细结果见 TEST-RESULTS.txt。

尚未在真实安卓手机、各浏览器或实时 F1 信号上实测，不能保证所有设备可用。
看到画面还需要核对节目内容；代码测试通过不等于当前赛事一定可播放。
前后台检查策略也不表示手机系统一定允许后台播放。

此版本从共享脚本自动生成，无远程 @require，也没有上游自动更新地址。
网页自身的播放器和直播服务仍需要联网。
