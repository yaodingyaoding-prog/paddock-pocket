# 围场口袋 · 微信原生客户端

[English](README.en.md) · [完整项目](https://github.com/yaodingyaoding-prog/paddock-pocket) · [现有网页版](https://f1.xiaodinglab.com/)

面向个人主体准备的微信小程序工程，使用 WXML、WXSS 和原生 JavaScript。复用围场口袋现有赛事 API 和账号服务，四个主入口为赛程、积分、探索和我的。工程版本 **0.1.0**。

## 已准备的功能

- 赛季与分站切换、完整赛历、场次安排、倒计时、场次成绩。
- 赛道图片与参数、当地实时天气、按场次匹配的预报、明确的数据时间与弱网回退。
- 车手和车队积分，前五名折叠榜单、历史头像、车手档案和生涯成绩。
- 围场新闻、站内摘要，以及按赛季、分站、场次生成的 Bilibili / 腾讯视频回放搜索入口。
- 原有邮箱账号登录、注册、发送密码找回邮件、退出及会话清理。
- 与网页和 Android 共用云端关注车手、车队、10 套主题、12 种点缀色和时区；三位车手组成个人领奖台。
- 展示账号现有云端头像、原生分享比赛 / 新闻 / 车手路径、隐私说明。

小程序内的回放与观赛入口采用“复制链接，在浏览器打开”。浏览器扩展脚本、Android 原生观看窗口、网页 3D / 遥测组件，以及头像裁剪上传没有直接装入这个原生工程；这些页面需要后续平台适配。密码重置在邮件中的本站安全页面完成。微信手机号或一键登录需另行接入，并不等于现有邮箱登录。

## 导入开发者工具

1. 到[微信公众平台](https://mp.weixin.qq.com/)注册“小程序”，按实际情况选择**个人主体**。主体资料、协议、密码和管理员验证由本人处理。
2. 按后台要求补充名称、图标、服务类目、备案和资质。取得“开发管理 → 开发设置”中的 **AppID**。
3. 安装微信开发者工具，选择“导入项目”，项目目录选**本文件所在的 `native/wechat` 文件夹**，不要选 `miniprogram` 子目录；填写自己的 AppID。不要在工程里填写 AppSecret。
4. 如果已有 Node.js，也可在本文件夹运行 `node scripts/configure.cjs wx你的真实AppID`，写入 Git 忽略的 `project.private.config.json`。AppID 格式为 wx 加 16 位十六进制字符。
5. 在小程序后台“开发管理 → 开发设置 → 服务器域名”中，将 `https://f1.xiaodinglab.com` 按实际使用配置为 **request 合法域名**。当前图片由本地和同域提供；若工具或后台要求图片下载域名，也使用同一 HTTPS 域名。是否接受该域名及其备案，以后台校验为准。
6. 保持合法域名校验开启，编译后用 Android 微信和 iPhone 微信分别预览，按下方验收清单逐项检查。
7. 完善微信后台的用户隐私保护指引、服务类目、备案及其他要求，再上传体验版、提交审核。工程交付不代表已经发布或通过审核。

无需购买服务器或把 Supabase / Resend 密钥复制进小程序。客户端只访问现有本站接口。

## 开发、数据与安全

运行时不依赖 npm 包。ZIP 中的资源与数据已生成，可直接导入。维护代码时，在完整仓库根目录执行：

```powershell
node scripts/prepare-wechat.mjs
node native/wechat/tests/run.cjs
node native/wechat/tests/pages.cjs
# 生成独立源码 ZIP，默认放入仓库 .local-artifacts/
node native/wechat/scripts/package.cjs
# 可选：只读请求正式站公开接口，不涉及账号
node native/wechat/tests/live.cjs
```

资源生成器复用当前赛事快照、车手身份映射、赛道坐标及自编中文摘要，并压缩随包图片；保留第三方出处。`miniprogram/data/*.js` 是生成模块，不应手改。主包按小于 2 MiB 的保守预算检查；真实打包大小以微信工具为准。

账号偏好只在云端保存。设备保存的必要内容为会话、公开赛事缓存及私有头像临时文件。登录请求不自动重试，避免重复提交；同一客户端的账号请求串行执行以减少刷新会话冲突。账号数据不进入公开赛事缓存，服务端来源校验和数据归属保护保持启用。微信对自定义 Origin / Cookie 与响应 Cookie 的处理，必须在配置真实 AppID 后验收；模拟请求测试不能证明微信环境中的认证可用。

天气仅在页面可见时按条件刷新：场次开始前 30 分钟至结束后 30 分钟每 5 分钟；未来 48 小时内有场次时每小时；其他时段每 3 小时。可下拉或手动更新。无需维护者电脑一直开机，但小程序退到后台后不会保证持续刷新。本站后端仍负责真实天气源和共享缓存。已结束场次不会显示为未来预报，超出预报范围会明确标注。

## 验收记录与待办

本次进行了 Node 代码/配置/模板结构检查、模拟微信请求的会话与弱网测试、云同步状态机测试、天气与成绩格式测试，详情见 [测试记录](TESTING.md)。这些属于源代码与接口契约验证。

取得 AppID 后仍需在微信工具和真机逐项完成：

- 首次冷启动、弱网、断网重开、恢复网络及资源加载。
- 当前 / 历史赛季、分站、场次成绩、车手档案、天气时间。
- 邮箱注册 / 登录、关闭并重开后保持登录、退出立即清除、错误密码及限流提示。
- 网页与小程序双向验证主题、配色、时区、三位车手及车队同步。
- 云端头像显示、切换账号后的隔离、隐私说明、剪贴板、页面分享。
- Android 微信、iPhone 微信与不同字体大小下的布局。
- 服务类目、域名、备案与隐私指引的后台校验，以及审核要求。
