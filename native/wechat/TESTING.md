源码结构检查不使用微信编译器；模拟宿主不渲染 WXML，也不模拟微信网络代理或其安全规则。

本机对生产接口的一次并发读取耗时：天气 1,643 ms、赛季 2,195 ms、车手积分 2,442 ms、下一站 2,676 ms、赛历 2,824 ms、车队积分 5,293 ms、新闻 8,714 ms。它们是此次本机 Node HTTP 的端到端结果，包含网络和上游响应，不能当作微信首屏速度、普遍用户时延或性能承诺。小程序先展示带保存时间的内置赛程 / 新闻，再请求新数据。

原生运行目录控制在 2 MiB 的保守预算内，约 1.86 MB；生成器与测试会检查。PNG导航图标、本地现代车手图和赛道图随包提供，历史头像按本站同域读取。更完整的图片署名放在运行目录外的 `third-party/`，随工程 ZIP 一同交付。微信编译后包体以开发者工具显示为准。

## 2026-10-27 开发者工具验证

维护者已配置个人小程序 AppID，并在微信开发者工具 Stable 2.02.2608070（模拟基础库 3.17.5）导入、编译工程。刷新后台 request 合法域名后，模拟器已展示在线赛程、赛道当地天气及场次预报；车手与车队积分、新闻、游客账号页和车手档案均能加载。修复了原生按钮占据过多宽度导致积分榜车手姓名竖排的问题，并在模拟器重新编译后核对两个榜单。开发预览代码已上传微信并生成临时二维码，尚未提交正式发布。

## 微信真机与发布验收

开发预览二维码不等同于已发布的正式版；目前尚未完成微信真机测试或平台审核。特别是账号自定义 Origin / Cookie、Set-Cookie 获取、跨重启保持登录、合法域名与微信网络环境行为，必须实测；不会通过关闭现有服务端来源保护来假装通过。

2026-10-27 真机反馈：iPhone 上网站正常，小程序曾出现赛程、天气和登录请求异常；后续用户反馈已能登录，但赛程和积分显示不全。客户端新增脱敏的网络错误分类以协助排查，尚不能确认网络问题已完全解决。开发者工具 320 px 模拟器中已检查赛程切换按钮横向布局和积分榜头像裁切，仍需在真机检查新预览版。

用户反馈预览版缺少头像、赛道图和天气。动态资源已显式加入打包配置，天气请求提前并显示加载 / 失败状态；新预览已生成，是否解决真机问题需等待真机反馈。开发者工具显示编译后代码包约 411 KB，尚未独立核实资源实际包含情况。

用户随后反馈天气已恢复，头像和赛道图仍未显示。将本地车手、车队和赛道资源由 WebP 转为调色板 PNG，并对线上历史头像启用 WebP 解析。重新预览时，开发者工具显示代码包由约 411 KB 增至约 1.6 MB，模拟器可展示图片；再次压缩后本地运行目录 1,499,728 字节。真实 iPhone 的 PNG 展示仍未独立验收。
